# Teachback demo

Suggested duration: 90–120 seconds.

1. Explain the problem: rereading notes can feel familiar without revealing misunderstandings.
2. Show the notes and a flawed explanation. For a reproducible walkthrough, use the sample button and disclose that its feedback is fixed.
3. For a real AI demonstration, edit the explanation to exit sample mode, agree to send it to Gemini, and request feedback. Make this distinction visible in the recording.
4. Open the feedback: show one misconception and its matching passage. Explain that a matching passage is evidence to inspect, not a guarantee of correctness.
5. Answer the practice question and rewrite the explanation in your own words.
6. Generate the receipt, show the before/after text, and download it.
7. Close with limitations: AI can misinterpret notes, scanned PDFs need OCR elsewhere, and one improved answer does not prove lasting mastery.

Use original non-sensitive example material. Never record API keys, environment files, or private notes. Verify real inference before recording; a sample-only walkthrough does not demonstrate the model integration.
